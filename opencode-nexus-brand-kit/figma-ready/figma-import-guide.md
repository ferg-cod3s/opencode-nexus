# Figma Import Guide

1. Import all SVG files from `svg-icons/`.
2. Create color styles from `design-system/tokens.json`.
3. Create text styles:
   - Display / Orbitron / 56, 40, 28
   - Body / Inter / 18, 16, 14
   - Mono / JetBrains Mono / 14, 12
4. Create components:
   - App Icon / Primary
   - App Icon / Agent Active
   - App Icon / Secure
   - Logo Lockup / Horizontal
   - Status Ring / Idle, Connecting, Active, Syncing
5. Use the landing page files as layout references.
