# OpencodeNexus Design System

## Positioning
**OpencodeNexus** is a command-and-control brand for agent/runtime/network orchestration.

Tagline: **Connect. Coordinate. Conquer.**

## Core Visual Language
- Central `X`: execution core / command node
- Ring system: control boundaries / runtime layers
- Radial nodes: agents, tools, endpoints, services
- Dark surface + silver geometry: premium infrastructure feel
- Green = active/healthy, blue = syncing, red = alert

## Recommended Typography
- Display: Orbitron
- Body: Inter
- Mono/CLI: JetBrains Mono

## App Icon Rules
- Keep the central X readable at 16px.
- Use no more than one accent color per state.
- Avoid tiny node detail below 64px.
- Primary icon should remain monochrome unless communicating runtime state.
