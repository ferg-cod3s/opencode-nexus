# OpencodeNexus Brand Kit

This package contains a starter production brand system for OpencodeNexus.

## Included

- `design-system/` — tokens, colors, typography, brand rules
- `figma-ready/` — Figma import/setup guide
- `svg-icons/` — scalable production SVG assets
- `motion-kit/` — CSS animated logo preview and motion states
- `landing-page/` — Astro + Svelte landing page starter
- `cli-branding/` — ASCII logo and terminal theme script

## Quick Start

### Landing Page
```bash
cd landing-page
npm install
npm run dev
```

### Motion Preview
Open:
```bash
motion-kit/animated-logo.html
```

### CLI Branding
```bash
./cli-branding/terminal-theme.sh
```
